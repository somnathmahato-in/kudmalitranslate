# 🌾 Kudmali Translate

An easy-to-use online translation tool to translate Hindi and Bangla language into the Kudmali language. Preserve and learn Kudmali with our efficient translation service.

[Kudmali Translate](https://kudmalitranslate.somnathmahato.in)

---

## ✨ Features

- **Multi-Language Support:** Translate seamlessly from Hindi and Bangla to Kudmali.
- **Cultural Preservation:** Built to help users preserve, promote, and learn the Kudmali language easily.
- **Fast & Responsive:** Clean UI optimized for speed and low network usage.
- **Cross-Platform:** Accessible on both Web browsers and Mobile devices.

---

## 🚀 How to Use

1. Visit the portal at [kudmalitranslate.somnathmahato.in](https://kudmalitranslate.somnathmahato.in).
2. Select your source language (Hindi or Bangla).
3. Type or paste your text to get instant Kudmali translations.
